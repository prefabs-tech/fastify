# Conventions

Patterns this repository expects you to follow. When a convention is enforced by tooling, that is noted.

# Concepts

- [Enforced and Observed Conventions](enforced-and-observed-conventions.md) - Which contribution rules are actually enforced by a hook, linter, type check, or CI, and which are patterns the code follows by habit, including where the habitual patterns are broken.
- [Dependency Layout](dependency-layout.md) - Where a dependency goes (peerDependencies with a dev pin, or dependencies), why sibling packages are pinned to the lockstep version, and how security overrides and the strict CI install enforce it.
