# fastify-mailer

**Responsibility:** one `fastify.mailer` for the app, with template compilation and a non-production safety valve. It does not queue, retry, or render any emails of its own apart from the test email.

## Registration
1. Resolve options, falling back to `fastify.config.mailer` ([migration](../architecture/plugin-options-migration.md)).[^plugin]
2. `createTransport(transport, defaults)`, where `transport` is SMTP options.
3. Add two compile plugins, in this order:[^plugin]
   1. `nodemailer-mjml`, which only receives `templating.templateFolder`, with `validationLevel: "soft"`.
   2. `nodemailer-html-to-text`.
4. Build `mailer = { ...transporter, sendMail }` and decorate `fastify.mailer`.[^index] **It throws `fastify-mailer has already been registered` on a second registration.**[^plugin]
5. If `test.enabled`, register a `GET <test.path>` route that renders an MJML test email and sends it to `test.to`.[^router] The route has no preHandler.

## The `sendMail` wrapper
1. Template data merges as `config.templateData` overlaid by `userOptions.templateData`.
2. **If `recipients` is non-empty, `to` is replaced with `recipients`, and `cc` and `bcc` are cleared for every message.** The type's JSDoc: "Any email sent from the API will be directed to these addresses."[^plugin][^types]
3. With a callback it delegates in callback style; otherwise it returns the promise.

> Inference, to verify: `...transporter` copies only the transporter's own enumerable properties. Methods defined on nodemailer's class prototype, such as `verify` and `close`, may therefore be absent from `fastify.mailer` at runtime, even though `FastifyMailer` is typed as `Transporter`.

## Config (`MailerConfig`)
`defaults` (requires `from: { address, name }`), `recipients?`, `templateData?`, `templating` (nodemailer-mjml options, of which only `templateFolder` is used), `test?`, `transport`.[^types] The `ANALYSIS.md` file classifies each passthrough.[^analysis]

## Depended on by
[user](user.md) sends invitation, verification, reset-password and duplicate-email-warning emails. `@prefabs.tech/fastify-config` is only an optional peer here.[^pkg]
